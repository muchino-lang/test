# 大学向けテレアポ トーク分析（リユースPC / BYOD）

対象：大学法人向けテレアポ・ロープレの文字起こし2本の分析まとめ。

- パターンA：**大学本体（情報システム部）** 向け … 学生・保護者の負担軽減という「教育的・福祉的視点」で語る
- パターンB：**大学の事業会社** 向け … 手間なく利益が出るという「ビジネス的視点」で語る

---

## パターンA：大学本体（情報システム部）向け

### 1. 全体の流れ

| # | ステップ | 内容 |
|---|---|---|
| 1 | フロント（受付突破・部署確認） | 自己紹介と合わせ、事前にサイトで調べた「BYOD所管の情報システム部」へピンポイントに取り次ぎ依頼 |
| 2 | 背景・課題の提示（共感の獲得） | 新品パソコンの高騰（10万〜30万円）と保護者の経済的負担という、大学側も無視できない社会的課題を提示 |
| 3 | 実績と安心感の提示（信頼の獲得） | 全国50校の導入実績、リユースPCでのトップシェア、4年保証という安心材料 |
| 4 | 懸念点の先回り解消 | 中古PCで最も懸念される「バッテリー寿命」に対し、50%以下での無制限交換・修理、次年度の純固体式モバイルバッテリー付属検討に言及 |
| 5 | クロージング（アポ打診・確定） | 「出張の機会」「実機の確認」「他校の事例紹介」を大義名分に、具体的な日時（来月23日10時）をピンポイント提示して確定 |

### 2. トークの要点（キーフレーズ）

- **ターゲットの明確化**：「BYODを所管されている情報システム部様へ」
- **社会的背景（フック）**：「新品パソコンの価格高騰（20万〜30万円）」「入学金等で経済的に厳しいご家庭への選択肢」
- **リユースの不安解消**：「推奨スペックをクリア」「4年間の長期保証」「バッテリー50%未満で無制限交換」
- **未来への付加価値**：「爆発しない純固体式モバイルバッテリーの展開検討」
- **アポの理由付け**：「実機を見てみないとわからないと思うので」

### 3. 優れている点（真似すべきコツ）

- **「実機確認」という断りにくい理由付け**
  カタログや口頭だけでは伝わらない中古のクオリティを「実機をお持ちします」と言うことで、相手の「見て確かめたい」という心理を刺激している。
- **ネガティブ（中古への不安）への先回り対応**
  相手が「でも中古だしな…」と思う前に、4年保証・バッテリー交換無制限を差し込み、反論の余地を事前に潰している。
- **具体的な日時指定によるクローズ（限定感）**
  「いつがよろしいですか？」ではなく「出張の機会があり、23日の10時はいかがですか？」と提案することで、相手はスケジュール帳を確認するだけ（YES / NO）の状態になり、承諾率が上がる。

### 4. さらに打率を上げるための改善のコツ

- **一文を短くし、「〜というところで」の重複を減らす**
  緊張や熱意から繋ぎ言葉が連続し、一文が長くなる傾向がある。「〜です。」「〜でございます。」と一度区切ると、電話越しでもクリアに聞き取りやすい。
- **大学側のメリット（ベネフィット）をもう一押しする**
  学生の経済的負担軽減に加えて、「大学側（情報システム部様）のサポートの手間や負担も、弊社の4年保証で巻き取れます」というニュアンスを入れると、担当者自身のメリットになり前のめりになってもらいやすい。

### 総合評価

事前準備（BYODの所管部署調べ）から、課題提起、不安解消、ピンポイントアプローチまで、テレアポの教科書のような完成度の高いトーク。

## パターンB：大学の事業会社向け

相手が「利益や運営効率を重視するビジネス組織」であることを前提に、**ビジネス上のメリット（利益・工数・リスク回避）**にフォーカスした構成。

### 1. 全体の流れ

| # | ステップ | 内容 |
|---|---|---|
| 1 | フロント（受付〜担当者呼び出し） | 実績（全国50校・トップシェア）を伝えつつ、「御社のサイトを拝見した」「事業のプラスになる提案」と商談として関心を引き、担当者へ繋ぐ |
| 2 | 課題と実績の提示（担当者パート開始） | 新品PC高騰という背景に対し、「リユースPCのシェアを3割〜5割に伸ばして成功している他校の事例」を出し、市場のニーズを証明 |
| 3 | ビジネスモデルとインセンティブの提示（最大のフック） | 「古物商の資格は不要」「ECサイトは弊社が構築」「新品より高い手数料（1台1万円以上）」というローリスク・ハイリターンなスキームを提示 |
| 4 | 懸念点（工数・クレーム）の先回り解消 | 「問い合わせは全て弊社が対応」「2700台のうちクレームは年1〜2件」という数字で不安を払拭 |
| 5 | クロージング（ピンポイント日程提示） | 「細かい説明やディスカッション」「来月の出張」を大義名分に、「8月24日の11時」とピンポイント指定して確定 |

### 2. トークの要点（事業会社に刺さるキーワード）

- 「御社の事業のプラスになる（売上・利益）」
- 「古物商の資格は不要（法的なハードルの排除）」
- 「紹介料として1台あたり1万円以上（具体的なインセンティブ）」
- 「問い合わせの工数はすべて弊社が持つ（業務負担ゼロ）」
- 「2700台のうちクレームは1、2件（高品質の証明）」

### 3. 抜群に上手い理由（コツ）

- **「紹介ビジネス（取次のみ）」であると割り切らせた点**
  「ECサイトの構築も運営もすべてリングロー側がやる」と言い切ることで、「仕入れや在庫のリスクがない」と瞬時に理解させている。
- **クレーム発生率を「具体的な数字」で伝えた点**
  事業会社が最も恐れるのは「購入した学生・親からのクレーム対応で自分たちの業務が炎上すること」。「2700台中、年1〜2件」と具体データで示すことで一気に安心感を与えている。
- **他校の「成功シェア（3割〜5割）」というパワーワード**
  「リユースを選ぶ学生がこれだけいる＝それだけ御社の手数料収入になる可能性がある」と未来の利益を想像させ、前向きな検討を引き出している。

### 4. さらに打率を上げるための改善のコツ

- **接続詞（〜というところ、〜という形）の整理**
  熱量が高まると1文に複数回入る傾向がある。
  （例）「ご相談できないかなというようなところでご連絡をさせていただいたというところでございますが」
  → 「〜と思い、ご連絡いたしました。こちらの件、ご所感はいかがでしょうか？」と言い切ると、プロフェッショナルで自信に満ちた印象になる。
- **「新品の商社様（加賀ソルネット様等）との共存」をより強調する**
  事業会社は「すでに付き合いのある新品PC商社との関係を壊したくない」と考える場合がある。「既存の新品の枠はそのままで、経済的に厳しい方向けの『第2の選択肢（受け皿）』として並列で置くだけでいい」と明確に伝えると、心理的ハードルがさらに下がる。

## 相手別トークの使い分け

| 観点 | 大学本体（情報システム部） | 大学の事業会社 |
|---|---|---|
| 訴求軸 | 教育的・福祉的視点 | ビジネス的視点 |
| 刺さる価値 | 学生・保護者の経済的負担軽減 | 手間なく利益が出る |
| 不安の中心 | 中古品の品質・スペック・バッテリー | サポート工数・クレーム対応 |
| 解消材料 | 推奨スペック適合／4年保証／バッテリー無制限交換 | 問い合わせは全て弊社対応／2700台中クレーム年1〜2件／古物商不要 |
| 決め手 | 実機確認 | 紹介料（1台1万円以上）・他校シェア3〜5割 |
| クロージング | 出張機会＋日時ピンポイント指定 | 出張機会＋日時ピンポイント指定 |

## 共通チェックリスト（架電前・架電中）

- [ ] 事前に相手サイトを確認し、BYOD／PC販売の所管部署を特定したか
- [ ] 相手の属性（大学本体／事業会社）に応じて訴求軸を切り替えたか
- [ ] 実績（全国50校・トップシェア）を早い段階で提示したか
- [ ] 相手が言い出す前に、中古への不安（品質・保証・クレーム・工数）を先回りで潰したか
- [ ] 相手自身のメリット（担当者の手間削減／会社の利益）に触れたか
- [ ] 既存取引先（新品商社）との共存を明言したか ※事業会社向け
- [ ] クロージングは「いつがよいか」ではなく、日時をピンポイントで提示したか
- [ ] 一文を短く区切り、「〜というところで」の重複を避けたか
