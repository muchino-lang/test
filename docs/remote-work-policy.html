R∞PC事業部 在宅勤務に関する方針（素案）

社内ドキュメント / R∞PC事業部 ・ 素案

1. 基本方針

当事業部は原則出社とする。在宅勤務は制度として推奨するものではなく、十分な実績と信頼に基づき、課長が個別に認めるものである。

2. 在宅勤務の対象

主任相当以上の職位にあり、かつ以下を満たす者に限り、課長判断で在宅勤務を認める場合がある。

営業職の場合売上・成果で継続的に結果を出しており、業務遂行に関する信頼が確立されていること。
バックオフィス・制作職の場合自身の業務量・工数を客観的に可視化でき、スキル水準を含めて第三者が見ても納得できる形で証明できていること。

3. 主任未満の者について

原則として在宅勤務は認めない。外出先からの直帰についても、事前に課長の承認を得ること。

バックオフィス・制作職においては、オフィスに常駐し、急な依頼や現物対応にフレキシブルに応じられる体制を維持すること自体が求められる役割である。

4. 在宅勤務の継続について（対象者向け）

在宅勤務は実績と信頼に基づいて認めているものであり、権利ではない。在宅勤務の可否は、業務姿勢・業務態度に基づき判断する。業務姿勢・業務態度の状況により、在宅勤務を取り消す場合がある。

5. 例外対応

体調不良（出社は難しいが業務は可能な程度）、悪天候・交通機関の大幅な乱れ、家庭の急な事情については、職位に関わらず当日始業前に課長へ連絡の上、個別に判断する。

6. 運用

本方針は課長の判断のもと運用し、必要に応じて見直す。
