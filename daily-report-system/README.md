# 日報 × スキルマップ蓄積システム

`index.html` をブラウザで開くだけで動く単一ファイルのアプリです。インストール・サーバー・通信は一切不要（社内PCにファイルを置くだけ、共有フォルダ配布可）。

## これで何が解決するか

評価シート（Excel）は「作って終わり」になりがちで、毎日見ないと存在しないのと同じ。
このシステムは **日報を書く＝スキルマップに実績が1件積み上がる** という構造にして、見る強制力を作ります。

- 毎朝ひらくと **「今日の重点3項目」** が強制表示される（記録が薄い項目・久しく触れていない項目から自動出題、フェーズとレベルが偏らないよう選定）
- 日報は **スキル項目に紐づけた実績を最低1件書かないと保存できない**
- 積み上がった実績はスキルマップ上で **グラデーション（濃さ）** として可視化される
- 評価面談の時には自己評価が既に埋まっており、**薄い箇所＝これから取りにいく穴** が一覧で出る

## 一番の障壁（78項目から該当項目を探す作業）への対応

目視で探すのは現実的ではないため、2つの入口を用意しています。

1. **🤖 AIに割り当てさせる（主）** — 日報の記述＋スキルマップ78項目＋判定ルールを組み立てたプロンプトをワンクリックでコピー。ChatGPT / Claude 等に貼って実行し、返ってきたJSONを貼り戻すと実績行が自動生成されます（崩れた回答でも `S012` 形式のIDを拾うフォールバックあり）。プロンプトは「行動基準込み（精度重視・約12,000字）」と「項目名のみ（軽量・約3,900字）」を切替可能。
2. **候補の自動提案（補助）** — 手動ピッカーを開くと、日報の記述に近い項目8件が上位に出ます（文字bigram＋IDF重み付け）。「与信申請」「楽楽販売」のように具体語が出る日報では強力ですが、抽象的な行動項目は拾えないため、AI判定の補助と考えてください。

**取り込んだ文章は必ず自分の言葉に直してください。** AIが書いた文をそのまま貯めても面談では語れません。

### すでに書きたい項目が決まっている人向け

3. **大枠から辿る** — 項目ピッカーの上部に業務フェーズ6つのタイル（項目数と記録済み数つき）が並びます。フェーズを選ぶとその中の分類チップだけに絞られ、大枠 → 分類 → 項目の2段で辿れます。フェーズ未選択時は分類が42件並んで邪魔なので畳んであり、「＋ 分類から直接えらぶ」で展開できます。レベル・スキル種別・状態の絞り込みと併用可能です。
4. **📌 ピン止め** — 自分が今期取りにいく項目をピン止めしておくと、**日報入力欄の実績セクションにワンクリック追加チップとして常駐**し、ピッカーでも常に先頭に表示されます。毎日同じ項目を積むタイプの人はここだけ見れば済みます。ピンはスキルマップの各行、またはピッカー内の 📌 ボタンでいつでも切替でき、追加済みの項目はチップが打ち消し線になります。スキルマップ側には「📌 ピン止めした項目だけ」表示のフィルタもあります。

## 日報の書き方（提案ではなく、自分で決めて動く）

日報で上司に「〜と思いますが、いかがでしょうか？」と許可を求めさせる形はとっていません。**自分で考えて、自分で決めて動く**書き方に統一しています。

| 項目 | 書くこと |
|---|---|
| 【こう考える（仮説）】 | 分析を踏まえて、自分はどう捉えたか |
| 【だからこうする（やること・試すこと）】 | 期日を切って言い切る（「〜する」「〜を試す」） |

チャット出力・Excel出力・AIプロンプトの見出しもすべてこの表現で揃えています。

## モ・ゲ・ジョ分析は任意

モ・ゲ・ジョ分析がなくても日報は提出できます。ただし1件も書いていないときは、入力欄と保存時に「1個でも課題を見つけて改善を目指すといいですね」という声かけが出ます（ブロックはしません）。

- **業務内容の行の 🔬 ボタン** を押すと、その業務内容をそのままテーマにしてモ・ゲ・ジョ分析を作成できます。「今日やったこと」から自然に深掘りへ入れます
- 各分析ブロックは**折りたたみ可能**です。ヘッダーの ▾ かヘッダー余白のクリックで開閉します（タイトル入力欄のクリックでは閉じません）
- 1日に複数のテーマを並べられます

## 「制約なし・期待値通り」を素直に出せる導線

モ・ゲ・ジョの「条件（ジョ）」に常に制約があるとは限りません。本人が「現状は期待値を満たしており特別な制約はない」と認識しているなら、それをそのまま書ける導線を用意しています。

- 条件欄のプレースホルダーに「特になければ『制約なし』『期待値通り』と記載」と明示
- ワンクリックで **「制約なし（期待値を満たしている）」** を入力できるチップ（既存の記述は消さずに追記、重複入力は防止）
- 「課題がない・現状で期待値通りと感じる場合は、その旨を選んでください（上司との期待値調整の起点になります）」の注記

狙いは **「本人は課題なしと認識しているが、上司から見ると未達」という認識のズレの可視化** です。「制約なし」と書かれた日報は、上司が本当の課題を認知させるための対話の起点になります。

AIプロンプト側にも判定ルールを追加しており、条件が「制約なし」等の場合は **記入者本人がそう認識しているという事実として記載どおりに受け取り、存在しない制約を推測で補わない** よう指示しています（条件が未記入の場合は「（未記入）」と出力し、「制約なし」と区別されます）。

## タブ構成

| タブ | 内容 |
|---|---|
| 今日の日報 | 重点3項目／日報入力（モ・ゲ・ジョ × アクション）／実績の紐づけ／チャット・Excel貼付用コピー |
| スキルマップ | 78項目の蓄積グラデーション、レベル・フェーズ・カテゴリ・スキル種別・状態（ピン止め含む）での絞り込み、📌ピン止め切替、自己評価／上司評価／備考、実績ログ、フェーズ×レベルのヒートマップ |
| 履歴 | 過去日報の全文検索・編集・再コピー・削除 |
| 評価面談シート | 提出数／カバー率／平均スコア、レベル別・フェーズ別の達成率、**足りない項目リスト**、語れる項目リスト、CSV・テキスト出力、印刷 |
| データ／設定 | JSONバックアップ・復元、既定氏名、テーマ、全削除 |

ピン止めもJSONバックアップに含まれます（`pins` フィールド）。

## 自己評価スコア

実績の記録件数から自動判定され、手動で上書きもできます。

| スコア | 意味 | 自動判定の目安 |
|---|---|---|
| 0 | 未着手 | 0件 |
| 1 | やってみた | 1〜2件 |
| 2 | できる場面がある | 3〜5件 |
| 3 | 安定してできる | 6〜9件 |
| 4 | 人に教えられる | 10件以上 |

## 出力

- **元Excel互換の自己評価シート(CSV)** — 元ファイルと同じ列構成＋実績件数・最終記録日・実績サマリー。既存のExcel運用にそのまま戻せます
- **実績ログ全件(CSV)** — 日付 × スキル項目 × 起きた事象
- **面談用サマリー(テキスト)** — 語れる項目と根拠、次に取りにいく項目

## データの保存場所（重要）

データはブラウザの **localStorage** にのみ保存されます。サーバーには一切送信されません。

- 別のPC・別のブラウザとは共有されません
- ブラウザのキャッシュ削除やPC入替でデータは消えます
- **月1回は「データ／設定」タブからJSONバックアップを取得してください**

チーム全体で一元管理したい場合は、各自が出力したCSVを共有Excelに集約する運用が現時点の想定です。

## スキルマップ項目の更新

`index.html` 内の `const SKILLS = [...]` が項目定義（元Excel「スキルマップ評価結果」シートから生成）です。
項目を追加する場合は **既存の `id`（現在 S001〜S078）を変更しない** でください。過去の実績ログがIDで紐づいているため、IDを振り直すと履歴が失われます。追加項目は S079 以降を使ってください。

各項目のフィールド：`id` / `lv`（0=土台, 1=レベル1, 2=レベル2, 3=レベル3）/ `ph`（業務フェーズ）/ `cat`（分類）/ `name` / `std`（行動基準）/ `pr`（1=商談ロープレ, 0=社内での動き）/ `sk`（0=考え方・立ち回り, 1=具体的なスキル）。
