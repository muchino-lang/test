# 一斉配信ファイル工房

一斉配信ツールに読み込ませる Excel（`一斉配信_YYYYMMDD.xlsx`）を、フォーム入力から生成する単一ファイルの Web ツールです。
`bulk-mail/index.html` をブラウザで開くだけで動きます（インストール・サーバー不要）。

## 何が楽になるか

従来の手作業 | このツール
--- | ---
F列に本文を書いて、G列の数式結果をF列にコピペ | 本文を1回入力するだけ。G列には `<br>` 変換済みの**値**を直接書き出し
C列の TEXTJOIN 数式を壊さないように K列以降へCCを入れる | 個別CC＋共通CCを自動で結合し、C列に値として出力（K列以降にも従来どおり展開）
宛先ごとに件名・本文を書き換え | `{{会社名}}` `{{名前}}` の差し込みタグで自動置換
アドレスの打ち間違いに気づけない | 形式チェックして該当行を警告表示

## 出力される列（元ファイルと同じ並び）

| 列 | 内容 |
--- | ---
| A | 名前 |
| B | To メールアドレス（複数可・区切り文字で連結） |
| C | Cc（個別CC＋共通CCを連結した**値**） |
| D | Bcc |
| E | 件名（差し込み後） |
| F | 本文記載内容（改行そのまま） |
| G | 本文（改行を `<br>` に変換済みの値） |
| H | ファイルパス |
| I | 会社名 |
| K〜 | そのCCアドレス（1セル1アドレス） |

C列の区切り文字は `;`（元ファイルと同じ）と `,` から選べます。

## 使い方

1. `bulk-mail/index.html` をダブルクリックしてブラウザで開く
2. 「配信内容」に件名と本文を入力（改行はそのまま。`{{会社名}}` などのタグが使えます）
3. 「共通設定」に全員分のCC・BCC・添付ファイルパスを入力
4. 「宛先リスト」に宛先を入力。Excelから4列（名前 / To / 個別CC / 会社名）をコピーして「Excelから貼り付け」でまとめて取り込めます
5. 「Excelをダウンロード」→ そのまま一斉配信ツールに読み込ませる

入力内容はブラウザに自動保存されるので、次に開いたときは前回の続きから始められます。

## 技術メモ

- 単一 HTML ファイル。Excel 書き出しは CDN の SheetJS 0.18.5 を使用（初回表示時にオンライン接続が必要）
- 入力の保存先は `localStorage`（端末内のみ。サーバーへは送信されません）
